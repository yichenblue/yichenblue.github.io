# Research article fonts

Self-hosted Latin-subset variable WOFF2 fonts, served only on posts with
`research_article: true`. The accompanying OFL license files apply to the
respective font families.

- IBM Plex Sans: normal, weights 400–700. Source: Google Fonts / IBM.
- Source Serif 4: normal and italic, weights 400–700. Source: Google Fonts / Adobe.

Downloaded from the official Google Fonts service on 2026-10-08. Fonts use
`font-display: swap`; system fonts remain available as fallbacks. MathJax
continues to supply mathematical glyphs independently.
